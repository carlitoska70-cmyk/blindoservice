# Presidio

Sorgenti del sito Presidio con strumenti per uso e manutenzione locale.

Inizia da `LEGGIMI_PRIMA.txt`. La guida tecnica e operativa è in
`GUIDA_COMPLETA_PRESIDIO.txt`; le verifiche sono in `COLLAUDO.txt`.

```bash
cd "$HOME/Desktop/blindoservice"
bash INSTALLA.command
bash AVVIA.command
```

Apri http://localhost:5173. Dati locali e produzione sono separati.
La documentazione originale del framework è in `docs/README_ORIGINALE_STARTER.md`.
